# Week 3 - Project Module 2: Password Cracking with Networkwalks Tools

## 📌 Overview
Demonstrated practical techniques for extracting hashes from password-protected PDF files and performing dictionary attacks using Networkwalks security tools.

## 🛠️ Tools Used
- **Networkwalks Hash Calculator** (Hash Extraction)
- **Networkwalks Password Cracker** (Dictionary Attack)

## 🎯 Key Steps Completed
1. Uploaded `My Locked PDF2.pdf` to extract the `$pdf$` hash.
2. Executed a dictionary attack against the extracted hash.
3. Successfully recovered the password (`password1`) and captured the flag.
